# Дизайн

## `prototype/`

Прототип интерфейса на Next.js, с которого начался визуальный язык продукта:
типографика, палитра, квадратные кнопки без теней, раскладка лендинга и отчёта.

**В рантайме не участвует.** Рабочий интерфейс живёт в [`../frontend/`](../frontend)
и раздаётся тем же FastAPI-сервисом; стилистика перенесена оттуда вручную.
Папка остаётся как источник дизайн-решений и часть истории проекта.

Запуск прототипа отдельно:

```bash
cd design/prototype
npm install
npm run dev
```
