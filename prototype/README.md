# Прототип проверки контрагентов

Моковый фронтенд сервиса проверки юридических лиц в стилистике Альфа-Банка.
Все компании, показатели и выводы внутри прототипа демонстрационные.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска откройте `http://localhost:3000`.

## Страницы

- `/` — лендинг с обычным и расширенным поиском;
- `/report` — моковый отчёт о контрагенте;
- кнопка «Перемешать пример» переключает три демонстрационных сценария отчёта.

## Проверка перед передачей

```bash
npm run lint
npm run build
```

Конфигурация OpenAI Sites находится в `.openai/hosting.json`.
