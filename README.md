# Xaxaton — ИИ-аналитик контрагентов

Основной интерфейс — диалог: пользователь проверяет компанию, задаёт узкие
вопросы, сравнивает контрагентов или подбирает их под условия сотрудничества.
Полный отчёт доступен отдельно как детализация ответа.

Backend рассчитывает факты из предоставленных данных, сохраняет происхождение
чисел и независимо показывает банковские `riskLevel` и `zskRiskLevel`.
Master Agent объясняет наблюдения; собственного общего скоринга нет.

## Что доступно

- Полная проверка по ИНН и уточнения «Почему?» / «Объясни проще» по контексту.
- Финансовые и юридические вопросы без повторного полного анализа.
- Сравнение 2–5 компаний, поиск по деятельности и показателям, подбор под задачу.
- Компактная сводка, качественный профиль AI, источники и экспорт в PDF.
- Внешние новости только в полной проверке, отдельно от внутренних фактов.
- Кросс-проверка связей в загруженном наборе и граф по запросу.
- Публичные статусы этапов обработки; текст ответа приходит целиком.

Данные статичны. История диалога хранится в памяти процесса. Наличие функции
в коде не доказывает качество каждого живого ответа: у behavioral evals
остаются содержательные ошибки. Desktop — текущий приоритет; мобильная
доработка приостановлена.
