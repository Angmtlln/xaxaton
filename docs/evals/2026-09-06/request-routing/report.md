## Ограничения содержательной приёмки

Повторный проход после объединения контекста:
[live-final.json.gz](live-final.json.gz). Все три технических проверки прошли:

| Реплика | Инструмент | Вызовов Master | Время, с |
|---|---|---:|---:|
| Платёжеспособность | get_financial_data | 2 | 12,261 |
| Суды и уже полученные финансы | get_legal_data | 2 | 4,741 |
| Почему? | без инструмента | 1 | 2,753 |

Второй ответ содержит оба домена; последующий ответ использует сохранённые
сведения. Полная проверка и внешний поиск не запускались. Объединение разных
снимков и вложенные копии предыдущего контекста дополнительно проверяются тестами.

Это **не semantic PASS всего анализа**. В первом проходе остались проблемные
формулировки:

- «весь этот рост оплачен чужими деньгами» — категоричная причинная интерпретация;
- «покрыть обязательство будет нечем, кроме текущих поступлений» — слишком
  сильный вывод о доступных ресурсах;
- связь распределения судебных дел по стадиям с конкретными годами названа
  без продемонстрированной проверки общего ключа.

В повторном проходе оговорка о независимых судебных агрегатах появилась, но
остались категоричные фразы вроде «любой сбой в поступлениях сразу создаёт
кассовый разрыв» и обобщение действия блокировки счетов. Semantic PASS также
не заявляется.

Эти примеры требуют отдельной содержательной работы с исходными данными и
поведенческими evals. Лексический фильтр выводов не добавлялся. Синхронный
semantic verifier по умолчанию остаётся отключённым.
Задержки 64 и 71 сек. также остаются ограничением; этот этап не доказывает
соблюдение SLO в 60 сек.

## Воспроизведение

Из `backend/`:

```bash
docker compose up -d --build api
.venv/bin/python scripts/smoke_agent_routing.py --output /tmp/request-routing-new.json
.venv/bin/python scripts/smoke_agent_routing.py --turns 1 4 5 --output /tmp/request-routing-mixed-new.json
```

Первый запуск проверяет все семь исходных реплик. Второй проверяет setup,
добавление юридических данных к финансам и контекстный «Почему?».
Результаты сохраняются после каждого хода; существующий файл не перезаписывается.
