# Исправление result_too_large: K15–K20

Ошибка размера устранена для исходного сравнения K15. Поведенческая приёмка всей цепочки не пройдена: **3 технических PASS, 3 FAIL**. Исходный полный baseline сохранён без изменений.

## Что изменено

`ToolRegistry.execute` считает символы компактного JSON (`separators=(",", ":")`), как при сериализации контекста агента. Лимит сравнения остаётся 80 000 символов. Данные, evidence и предупреждения не сокращаются.

Для реальных ИНН `6165169320`, `3711039473`, `7813664770` и `focus=both`: JSON с форматирующими пробелами — 82 058 символов; компактный — 76 319; нормализованный контекст Master — 72 414. Небольшая вариация размера возможна из-за latency metadata.

Регрессионный тест на исходном snapshot до исправления: 1 FAIL / 1 PASS. После исправления: сравнение проходит при 80 000, сохраняя data/evidence/warnings целиком; при 70 000 возвращается `result_too_large`. Вместе с существующими тестами сравнения и ограничения размера: **21 passed**.

Содержательные ответы не получили новую полную semantic-оценку: технический PASS не означает корректность всех интерпретаций. Маршрутизация, prompts и semantic failures в этом изменении не исправлялись.
