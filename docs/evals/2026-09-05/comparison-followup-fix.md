# Продолжение сравнения: исправление маршрутизации K16/K17/K19

**Исходные K15–K20: 6 технических PASS / 0 FAIL.** В предыдущем [прогоне после исправления размера](result-size-fix.md) было 3 PASS / 3 FAIL: K16/K17/K19 требовали ИНН при сохранённом comparison_context.

## Поведение

После сравнения вопросы без нового ИНН используют проверенный `comparison_context`, даже если слова о финансах или судах подсказывают инструмент для одной компании. Контекст сравнения имеет приоритет перед ранее выбранной одиночной компанией. В системное сообщение передаются ИНН всех сравниваемых компаний.

Повторное использование ограничено последней темой `comparison` и доменами в `focus`. Явные ИНН проходят обычную валидацию; запрос обновления, детализации или полной проверки не превращается в ответ из кэша сравнения. Новый пустой чат по-прежнему требует ИНН. После явного перехода к одной компании используются её данные.
