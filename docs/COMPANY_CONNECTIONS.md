# Внутренняя кросс-проверка

Проверка всего `contractors_audit.snapshot.json` (100 карточек, 06.09.2026)
нашла одну пару: ООО «ЛЗСО» 7805327192 и ООО «ЛЗСО» 4720028039.
Пять оснований: общий действующий учредитель, общий руководитель (ИНН
781132207821), взаимная relatedCompanies-ссылка (одно ребро), общие ссылки
на 4720031578 и 7819030480. Последних двух компаний нет в датасете, они не
проходили краткую проверку. Совпадений адреса, email, сайта и телефона нет.
249 записей relatedCompanies во всём наборе; только две направленные ссылки
ведут на другую карточку набора. Совпадение названия не считается связью.

`agent/connections.py` сравнивает только корневую компанию с набором последних
снимков. Помимо найденных типов поддержаны пересечение ролей учредитель/директор,
прямое владение и точные нормализованные контакты. Неактивный или неизвестный
статус учредителя не превращается в действующее владение. Контактные совпадения
и общие related-ссылки не доказывают аффилированность.

Полная проверка автоматически добавляет `connections` в ToolResult и trusted
context. Это максимум 6 соседей / 30 рёбер, один шаг, до 10 000 кандидатных
карточек и 4 секунд I/O; ограничения отражаются состоянием partial. Для соседей
одним запросом читаются полные последние снимки, существующие finance/legal
builders дают компактные наблюдения и пробелы. Дополнительных LLM-вызовов и
полных pipeline-прогонов нет. Ошибка этой функции не отменяет основной отчёт.
Пустой/неполный набор не доказывает отсутствия связей за пределами датасета.

DB impact: новая read-only view `core.v_connection_candidates`, без изменения
таблиц/данных. Она возвращает только паспорт, учредителей, контакты и связанные
организации. Для существующей БД применить:

```sh
docker exec -i contractors-db psql -U postgres -d contractors -v ON_ERROR_STOP=1 < backend/db/migrations/003_connection_candidates.sql
```

Для новой БД view включена в `backend/db/schema.sql`. Контракты Pydantic
расширены необязательным полем, старые ответы/сессии совместимы.
Проверки: `cd backend && PYTHONPATH=. .venv/bin/python -m pytest -q tests/test_connections.py`.
